UFIBER tool selector, speeds & feeds, troubleshooter, XEBEC converter and product builder as an Elementor widget and shortcode.

== Description ==
* Elementor widget "UFIBER Guide" (category NOGA MT) with start section, units, logo bar, height and frame styling.
* Shortcode: [ufiber_guide tab="speeds" units="inch" height="auto" brand="no"]
* Self-contained: the guide runs in a sandboxed frame, so it never clashes with your theme's CSS or scripts and sends no data to NOGA.
* Updates through the normal WordPress update screen from a JSON manifest or GitHub releases.

== Installation ==
Upload the zip under Plugins → Add New → Upload, activate, then open Settings → UFIBER Guide to set the update source.
